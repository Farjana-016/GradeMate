# 🎓 GradeMate

**A simple, thoughtfully designed academic grade calculator and performance tracker.**

GradeMate is an academic productivity web application designed to help students calculate their SGPA and CGPA, track academic performance, plan their target grades and manage calculation history — all in one place.

## ✨ Features

### 🏠 Dashboard

- View your current CGPA.
- Track your latest and highest SGPA.
- Monitor completed semesters.
- Quickly access all major sections.

### 📊 SGPA Calculator

- Calculate semester grade point average.
- Add and manage subjects, credits and grades.
- Support custom semester names.
- Save calculations to history.

### 🎓 CGPA Calculator

- Calculate cumulative grade point average.
- Manage semester-wise academic results.
- Import saved SGPA calculations.
- Keep track of overall academic performance.

### 🎯 Target CGPA Planner

- Set your desired graduation CGPA.
- Calculate the SGPA required in upcoming semesters.
- Plan your academic goals based on completed and remaining credits.

### 📚 Calculation History

- View previous SGPA and CGPA calculations.
- Review saved academic records.
- Keep calculation history organized.

### ⚙️ Settings

- Manage your profile.
- Customize academic preferences and grading scales.
- Choose decimal precision.
- Export and restore backups.
- Manage application data.

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript (ES6+)
- Browser Local Storage

## 🎨 Design Philosophy

GradeMate follows a vibrant royal violet theme with a clean, modern interface, simple navigation and responsive layouts.

The goal is to make academic calculations and performance tracking feel simple, organized and accessible across desktop, tablet and mobile devices.

## 💾 Data Storage

GradeMate uses browser Local Storage to save application data.

- Profile, preferences and calculation history are stored locally in the browser.
- Data is not automatically synchronized across devices or browsers.
- Users can export and restore their data through the Settings section.

## 🔮 Future Improvements

GradeMate may evolve through usability improvements, new academic features and enhancements based on real-world feedback.
